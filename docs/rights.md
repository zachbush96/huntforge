- Original implementation and HuntForge-authored queries use the repository's MIT license.
- CISA's KEV repository is distributed under CC0. HuntForge retains CISA attribution.
- FIRST provides public EPSS scores. HuntForge republishes a scoped subset of score facts with attribution.
- MITRE ATT&CK® Enterprise reference metadata travels with the upstream copyright and license in `reference/index.json`. MITRE ATT&CK is a registered trademark of The MITRE Corporation.
- HuntForge links public advisories and research by title, date and source location and writes its own factual summaries and evidence notes. The [source registry](../SOURCES.yaml) records each publisher's collection and reuse scope.
- HuntForge publishes selected factual observations and indicator values with provenance. Their listed presence applies to the context reported by the source.
