# Interface

The supplied HuntForge references guide the black-and-white dashboard and Hunt Card. The Brief uses a wide left navigation rail, a halftone globe, four metrics, paginated developments and a narrow operations column. Hunt Cards use the compact header, dark KQL viewer and a persistent schema column.

The content comes from the accepted release. Severity labels, validation scope, launch dates and counts follow the dataset. Decorative halftones use the generated raster asset. Long titles can shorten in the dense dashboard with the full title available in its record.

At smaller widths the navigation becomes a scrollable strip and operational or schema panels move below the main content. Search opens with the slash key. Query tabs support arrows, Home and End.
